# B4 首页分发、标签、作者主页与个人资料

日期：2026-10-15。范围对应开发规划 B4：DISC-01（首页精选/最新、标签总览与标签页、作者主页、分页、空态与精选回退）与 PROFILE-01（昵称/简介/头像修改、字段边界、默认头像、不能引用他人私有图片）。搜索属于 C1，点赞/收藏/关注与评论属于 C2/C3，精选的写入（管理员设置与排序）属于 D3：本阶段只**读取**精选并保证排序稳定。

本轮仅完成开发与迁移，未执行冒烟测试或全量回归；验证清单见第 6 节，交由后续测试执行。

## 1. 数据与迁移

新增迁移 `drizzle/0004_b4_featured_articles.sql`（不修改历史迁移）：

| 表 | 字段 | 约束 |
| --- | --- | --- |
| `featured_articles` | `article_id`（主键）、`position`、`selected_by`、`created_at` | `position >= 0`；索引 `(position, article_id)`；外键指向 `articles` 与 `users` |

- 精选读取按 `(position, article_id)` 正序，与架构第 5 节的排序口径一致；`article_id` 主键保证一篇文章只出现一次。
- 读取时只接受 `status='published'` 的文章：下架或删除后即使精选记录仍在，也不再展示（D3 负责在治理动作中清理记录）。
- 表已应用到本机开发库（`pnpm db:migrate` 通过版本历史校验）。

## 2. 公开读取（discovery 模块）

`src/modules/discovery`：`policy.ts`（页大小）、`cursor.ts`（游标编解码与校验）、`service.ts`（公开查询）、`http.ts`（接线）。

| 接口 | 行为 |
| --- | --- |
| `GET /api/v1/articles?mode=featured\|latest&tag=&author=&cursor=&limit=` | 公开列表；默认 `latest`；未知 `mode` 返回 400，非 UUID 的 `author` 返回 400 |
| `GET /api/v1/tags/:slug` | 标签详情 + 该标签最新公开文章首页；不存在返回 404 |
| `GET /api/v1/users/:id` | 公开作者资料 + 该作者已发布文章首页；不存在或非 UUID 返回 404 |

投影只取 `article_publications` 与公开用户字段（ID、昵称、头像媒体 ID），不拼接工作草稿、不返回邮箱/状态/版本/磁盘键。

**排序与游标**：最新用 `(first_published_at, id)` 倒序，精选用 `(position, article_id)` 正序，均按“排序键 + ID”比较，不使用 offset，因此翻页不会重复或跳过已有条目。游标是 base64url 的 JSON（`v/mode/scope/key/id`）：其中 `scope` 是排序方式与查询条件（标签、作者）的摘要，**变更查询条件时回到第一页**而不是复用别的列表游标；结构非法的游标返回 400 `CURSOR_INVALID`。微秒时间保留 PostgreSQL 文本（`to_char(... US)`），不在 JavaScript `Date` 中丢精度。

**列表页大小**：首页/标签/作者主页默认 10、上限 30；标签总览默认 50、上限 100，并使用 `(name, id)` 游标。

## 3. 页面

| 页面 | 内容 |
| --- | --- |
| `/` | 原型首页结构：hero、精选文章/最新发布切换、公开文章卡片、“写一篇文章”入口与标签入口 |
| `/tags` | 标签总览：名称、真实公开文章数、停用标记；停用标签仍可进入 |
| `/tags/:slug` | 标签页：公开文章数与停用说明 + 最新公开文章分页 |
| `/users/:id` | 作者主页：头像、昵称、简介、加入时间、公开文章数与分页 |
| `/settings/profile` | 资料编辑：昵称、简介、头像上传/移除、邮箱只读说明；非正常账号按既有口径被门禁拦截 |

- 卡片（`src/components/article-card.tsx`）展示标题、摘要、作者（链接作者主页）、首次发布时间、标签与精选标记；**不展示演示计数**。
- 精选为空且处于第一页时回退到最新发布，并显示“当前没有精选文章，先看最新发布。”；全站没有公开文章时展示明确空态与写作入口，不伪造示例内容。
- 分页只提供“下一页”（游标语义），排序稳定；`/tags`、`/tags/:slug`、`/users/:id`、`/articles/:id` 与首页都有对应 `loading.tsx`（列表加载态）。
- 头像统一由 `src/components/avatar.tsx` 渲染：有头像时读取受控媒体地址 `/api/v1/media/:id`，否则显示昵称首字；骨架用户菜单、账号页、作者主页、资料编辑共用。
- 两视口适配：卡片、hero、标签网格、作者资料卡在 ≤760px 单列/两列排布，头像与按钮换行显示。

## 4. 资料修改（PROFILE-01）

`PATCH /api/v1/me/profile`，请求体 `{nickname, bio, avatarMediaId}`：

- 复用 `authenticatedTransaction`（精确 Origin、会话 CSRF、事务内实时账号状态）：仅本人且正常账号可写；封禁账号被拒绝。
- 字段边界：昵称 2–30 码点、简介 ≤200 码点；未知字段一律拒绝（`strictObject`）。字段错误按统一协议返回 `fieldErrors`。
- `avatarMediaId` 必须是**本人已完成上传**的媒体：复用媒体引用校验（归属 + ready），引用他人私有图片或未完成上传返回 403/409；传 `null` 表示移除头像。
- 保存成功后客户端刷新服务端渲染结果，骨架中的昵称与头像立即更新；上传与保存失败都保留当前输入并给出中文原因。

资料读取不需要新接口：`UserDto` 增加 `bio` 与 `avatarMediaId`（会话查询一并取出），供骨架、账号页与资料页共用；公开作者资料仍由 discovery 单独投影，不暴露邮箱与账号状态。

## 5. 与其他阶段的关系

- **搜索**（C1）尚未实现：`/search` 仍是 A4 的占位页，discovery 模块未提供检索能力。
- **互动计数**（C2）尚未建表：卡片不显示点赞/收藏/评论数；本阶段提供的真实计数是标签与作者的公开文章数，取自 `publication_tags` 与 `articles`。
- **关注按钮与关注/粉丝列表**（C2）：作者主页当前只有资料与文章，不放置无实际行为的关注按钮。
- **精选写入与排序**（D3）：`featured_articles` 目前只被读取；治理动作、审计与理由在 D3 落地。
- **下架/复核**：下架文章立即从首页、标签页与作者主页消失（读取只认 `published`）。

## 6. 交给测试的验证清单

本轮未运行任何用例；以下为建议的最小覆盖，供测试执行方按现有 fixture 补写：

1. `tests/rules`：游标编解码（排序方式/查询条件变更时回到第一页、非法游标报错）、页大小钳制、`featured` 排序键、`profileSchema` 字段边界。
2. `tests/foundation` 或 `tests/api`：
   - 精选回退：无精选记录时首页回退最新；有精选时按 `(position, article_id)` 排序；下架/删除后立即从列表消失。
   - 分页：造出超过页大小的公开文章，验证最新与精选两种游标翻页不重复、不遗漏，且同时间发布用 ID 稳定排序。
   - 标签：停用标签的既有公开文章仍能读取，`publishedCount` 与真实关联数一致。
   - 作者主页：只返回公开资料字段（不含邮箱/状态），封禁作者的公开文章仍可读。
   - 资料：昵称/简介边界、未知字段拒绝、封禁账号被拒、引用他人私有媒体被拒、头像移除。
   - 公开读取不泄露草稿：存在未发布修订时，列表与作者主页只显示公开版本标题/摘要。
3. `tests/e2e`（桌面 + 手机）：首页空态与写作入口、精选为空回退提示、标签总览与标签页、作者主页资料与文章、资料编辑保存后骨架昵称/头像更新、头像上传后作者主页读取受控地址、两视口无横向溢出。
