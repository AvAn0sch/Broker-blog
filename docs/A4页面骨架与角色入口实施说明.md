# A4 页面骨架与角色入口实施说明

日期：2026-10-15。范围：全站 AppShell（顶栏、侧栏、搜索、头像菜单）、按游客/正常/封禁/管理员区分的真实角色入口与门禁页面、基础测试 fixtures。编辑器正文、草稿、发现、互动与治理页面从 B/C/D 起实现，本文不表示任何业务用例已验收。

## 1. 导航骨架

`src/components/app-shell.tsx` 位于根布局（`src/app/layout.tsx`），所有页面共用，包含：

- **顶栏**：品牌入口、关键词搜索（纯 GET 表单提交到 `/search`，无脚本也可用）、写文章入口、账号区。
- **账号区**：游客显示登录与注册链接；已登录显示头像菜单。
- **侧栏**：发现文章（`/`）与探索标签（`/tags`），当前分区用 `aria-current="page"` 标记（`side-nav.tsx` 使用 `usePathname`）。
- **主内容**：由布局统一提供 `<main>` 地标，页面不再各自渲染顶栏。

AppShell 只读取会话（`sessionToken` + `readSession`），不写入任何 cookie；匿名浏览器绑定仍由认证接口建立。

## 2. 角色入口矩阵

可见入口由纯函数 `userMenuEntries`（`src/modules/identity/navigation.ts`）决定，规则测试覆盖四种组合。

| 角色 | 顶栏写作入口 | 头像菜单入口 |
| --- | --- | --- |
| 游客 | 显示，指向 `/editor/new`，由该页跳转登录并保留返回地址 | 无菜单，显示「登录」「加入社区」 |
| 正常成员 | 显示 | 通知中心、内容管理、我的收藏、我的举报、个人设置、退出登录 |
| 封禁成员 | 不显示 | 通知中心、内容管理、我的收藏、我的举报、退出登录；菜单标注「已封禁 · 仅可只读」 |
| 正常管理员 | 显示 | 上述成员入口 + 管理后台 |
| 封禁管理员 | 不显示 | 与封禁成员一致，无管理后台入口 |

菜单交互（`src/components/user-menu.tsx`）：点击/触屏切换；`ArrowDown` 打开并聚焦首项；`Escape` 关闭并回到触发按钮；焦点移出容器或点击菜单外区域关闭；`aria-expanded`/`aria-controls` 与隐藏属性保持同步。

## 3. 页面与门禁

门禁由 `pageUser`（`src/modules/identity/http.ts`）提供：读取当前会话；未登录跳转 `/login?returnTo=<本站路径>`；封禁账号访问写入类页面时跳转 `/account?notice=banned-write`。写接口仍必须使用 `authenticatedTransaction`；本阶段不新增接口与写入操作。

| 路径 | 门禁 | 当前内容 |
| --- | --- | --- |
| `/` | 公开 | 现有首页，换用全局骨架 |
| `/tags` | 公开 | 标签浏览占位，说明真实列表随发现功能接入 |
| `/search` | 公开 | 关键词回显与未开放说明；不返回任何文章数据 |
| `/editor/new` | 登录且正常状态 | 编辑器占位；封禁账号跳转账号页提示 |
| `/notifications` | 登录（封禁可只读） | 通知占位；封禁账号显示只读提示 |
| `/me/articles` | 登录（封禁可只读） | 内容管理占位 |
| `/me/bookmarks` | 登录（封禁可只读） | 我的收藏占位 |
| `/me/reports` | 登录（封禁可只读） | 我的举报占位 |
| `/settings/profile` | 登录且正常状态 | 资料编辑占位 |
| `/login`、`/register`、`/account`、`/admin` | 沿用 A3 | 行为不变，改用全局骨架 |

占位页面不写入数据、不展示示例文章或假计数，也不显示演示成功状态；搜索页只回显关键词。

## 4. 原型差异与范围控制

按[系统架构设计](系统架构设计.md)的差异表执行，本阶段落实的差异：

- 原型搜索的标题/正文/作者范围控件不进入实现；标题、标签与正文的综合搜索在 C1 按产品基线提供，`/search` 当前只保留关键词入口。
- 原型的「管理后台演示」「登录/注册演示」入口替换为真实角色入口；未登录用户看到真实登录与注册。
- 原型头像菜单的未读徽标为演示计数；本期不显示任何未读数字，真实未读在 C4 随通知功能提供。
- 原型用鼠标悬浮打开菜单；架构基线要求菜单支持触屏和键盘，实现改为点击/触屏与键盘开关，避免悬浮与点击切换互相冲突。
- 原型侧栏底部的「示例内容」声明替换为真实品牌文案。

## 5. 测试与报告

- `tests/rules/navigation.test.ts`：入口纯函数在正常、封禁、管理员、封禁管理员下的可见入口与路由（4 项）。
- `tests/e2e/shell.spec.ts`：游客骨架与搜索/标签导航、成员菜单与键盘开关、管理员与封禁状态切换下的入口与门禁（3 项，桌面与手机项目各执行一次）。
- `tests/fixtures/accounts.ts`：通过真实注册表单创建账号；封禁与角色作为边界状态直接落到测试账号；注册提交对可重试的 503 按提示重试。

- `playwright.config.ts`：单用例超时 30 秒提高到 60 秒，覆盖开发模式按需编译与并行注册的哈希并发上限。
